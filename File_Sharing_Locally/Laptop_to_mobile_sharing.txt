By Python server =>

1. on phone hotspot and connect laptop. hotspot setting 5GHz for speed
2. on laptop, go on file location which folder have file than you want to share
3. open cmd here, 	I.  "ipconfig" -> note IPv4 Address (ex. 10.78.141.2)
			II. server start command -> "python3 -m http.server 8000" -> here note port 8000
4. on Phone open browser and hit IPv4 address with port number (ex. 10.78.141.2:8000) it's showing that laptop folder directory here
